# Member 4 — Developer Onboarding & Quickstart Guide

### 1. Requirements
- Python 3.12+ (or Windows `py` launcher)
- Django 6.1+, djangorestframework, drf-spectacular, reportlab, pydicom, pytest

### 2. Launch Local Server
```bash
cd backend
py manage.py runserver 127.0.0.1:8000
```
- Open Swagger UI: `http://127.0.0.1:8000/api/docs/`
- Open Member 4 UI: `http://127.0.0.1:8000/frontend/member4-lis-ris/index.html`
